# Security Policy

## Supported versions

Only the latest `main` branch and the most recent release receive security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's "Report a vulnerability" flow:
<https://github.com/atomikfactory/atomik-meeting-recorder/security/advisories/new>

Do not open a public issue or pull request for a security problem. Include the affected version or commit, your platform, and steps to reproduce. You can expect an acknowledgement, and we will coordinate a fix and disclosure with you through the advisory.

## Privacy model

The app processes recordings, transcripts, and summaries locally and makes no cloud requests unless you explicitly enable an optional integration (see the README).
